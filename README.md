## Changelog

### Version 6.1.0
- **Keyboard Event Types Support**: Added support for separate sounds on keydown, keyup, and keypress events
- Sound profiles now support three distinct event types for more realistic typing experiences
- Improved fallback logic: specific key events fall back to default, missing defaults result in no sound
- Updated all 21 sound profile YAML files to new event-based format
- Typewriter profile now features keyup sounds for authentic mechanical feel
- Drum profile showcases keypress ghost notes when holding keys
