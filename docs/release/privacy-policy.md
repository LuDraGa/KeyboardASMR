# Keyboard ASMR Privacy Policy

Last updated: June 5, 2026

Keyboard ASMR plays customizable keyboard sound effects in your browser.

## Data Keyboard ASMR Does Not Collect

Keyboard ASMR does not collect typed text, raw key values, passwords, form contents, website content, raw page URLs, browsing history, location, payment information, health information, authentication information, or personal communications.

## Local Settings

Keyboard ASMR stores extension settings so the extension can remember your preferences. These settings may include selected sound profile, mute state, volume, theme, and diagnostic sharing preference.

These settings are stored with Chrome extension storage APIs.

## Aggregate Usage Analytics

If analytics is enabled in a release build, Keyboard ASMR collects privacy-safe aggregate usage data to understand reliability and product usage.

This may include extension install/update events, popup opens, selected sound profile, profile preview and selection counts, daily per-profile key event counts, sound playback counts, dropped sound counts, error classes, compatibility modes, volume buckets, first-sound latency buckets, and diagnostic/report actions.

Key event analytics are counts only. Keyboard ASMR does not send which keys were pressed or what was typed.

When analytics is configured, Keyboard ASMR stores an anonymous analytics client ID in Chrome local extension storage. This ID is used only to group aggregate extension analytics events.

## Diagnostic Reports

If diagnostic sharing is enabled, Keyboard ASMR can send a support report only after you opt in or manually share it from the extension popup.

Diagnostic reports may include extension version, user agent, platform, language, selected sound profile, mute and volume settings, local audio/profile status, compatibility mode, error codes, timing buckets, and category-level key counters.

Diagnostic reports exclude typed text, raw key values, raw page URLs, browsing history, and website content.

## How Data Is Used

Data is used only to improve Keyboard ASMR reliability, understand aggregate sound-profile demand, and support users who report issues.

Keyboard ASMR does not sell user data. Keyboard ASMR does not use user data for personalized advertising, retargeted advertising, interest-based advertising, creditworthiness, or lending purposes.

## Sharing and Processing

If analytics is configured, aggregate analytics data is processed by Google Analytics through a developer-controlled Cloudflare Worker proxy.

If diagnostic upload is configured, diagnostic reports are sent only to a developer-controlled support endpoint.

All remote analytics and diagnostic endpoints must use HTTPS.

## User Choices

You can disable diagnostic sharing from the extension popup.

Removing the extension clears extension-local storage according to Chrome's extension storage behavior.

## Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Keyboard ASMR's use and transfer of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
